# جزیره الفبا

پروژهٔ مرحلهٔ اول فلاتر برای آموزش فارسی پایهٔ اول.

## اجرا

```bash
flutter pub get
flutter run
```

## ساخت اندروید

```bash
flutter build apk --release
```

## وضعیت

این نسخه شامل معماری محتوای جدا، بانک کنترل‌شدهٔ درس اول، ۸ تمرین تعاملی، ذخیرهٔ پیشرفت، گزارش سادهٔ والدین و تست‌های محتوایی است. بانک کامل ۲۲ درس و فایل صوتی در مراحل بعد تکمیل می‌شود.

اگر پوشهٔ اندروید وجود ندارد، ابتدا `flutter create --platforms=android .` را اجرا کنید.

## قرارداد فونت

رابط کاربری باید با خانوادهٔ Vazir رندر شود. تمام گلیف‌های تمرینی، حروف جعبه، تختهٔ کلمه، واژه‌ها و جمله‌های تمرینی باید با خانوادهٔ WmTahriri و فایل wm_Tahriri.ttf رندر شوند.

فایل Vazir-Regular.ttf در پروژه قرار داده شده و برای رابط برنامه ثبت شده است.

## هستهٔ محتوای آموزشی
تقویم اولیهٔ ۲۲ درس در `assets/content/lesson_calendar.json` قرار گرفته است.


نسخهٔ جدید شامل بانک دادهٔ ۲۲ درس، ۳۰ جمله برای هر سطح، مسیر قفل‌شدهٔ درس‌ها و تمرین‌های ارزیابی‌دار است. تصاویر و صوت‌ها هنوز نیازمند تولید و مجوز جداگانه‌اند.


هستهٔ جدید شامل ارزیابی آفلاین دست‌خط، موتور فرم‌های اتصال، قواعد حرکات، تشدید، نیم‌فاصله و پیشوند می است. صوت و تصویر به‌صورت وابستگی اجباری وارد نشده‌اند تا بعداً به داده‌های محتوا اضافه شوند.
